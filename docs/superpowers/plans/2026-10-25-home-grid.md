# Home grid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Home into an editable 12-column grid of blocks with layout themes and two data widgets (crypto, season premieres).

**Architecture:** A pure `home_grid` module owns the block model, geometry and collision reflow; `themes` holds presets; `view::home` draws each block in its grid rect; `State` adds grid navigation, edit modes and three overlays; a `feeds` worker fetches Binance/TVmaze data and poster images off the SDL thread.

**Tech Stack:** Rust 1.93, SDL2/GL ES renderer, serde, ureq/rustls, image.

**Spec:** `docs/superpowers/specs/2026-10-25-home-grid-design.md`

## Global Constraints

- Grid: 12 columns × 124 px, gap 24 px, row 100 px, left 84 px, top 150 px (logical 1920×1080).
- One block per kind; sizes (min, max, default) in cells: greeting (4×1, 12×3, 8×2), weather (4×1, 12×2, 8×1), favorites (6×2, 12×3, 12×2; min height 3 with names), inputs (4×1, 12×3, 12×1), crypto (3×1, 6×2, 4×1), premieres (6×2, 12×3, 12×2).
- Network: fixed HTTPS origins only (`api.binance.com`, `api.binance.us`, `api.tvmaze.com`, `static.tvmaze.com`), no redirects, timeouts ≤ 10 s, JSON ≤ 1 MiB, images ≤ 2 MiB; worker thread only.
- Preferences: `home_layout: Vec<Block>`, `home_theme: String`; malformed → Classic layout.
- Every new string in all 7 languages (en, de, es, zh, pt, it, ru).

## Review Focus

- Saved layout with overlapping/out-of-range blocks (old or hand-edited prefs) → normalised, no overlap, nothing off-grid.
- Favourites with names turned on in a 2-row block → block grows to 3 rows, captions not clipped.
- Many inputs in a narrow inputs block → block grows to the rows it needs.
- Feeds offline or blocked → widget shows a quiet "unavailable" line, Home still works.
- Edit cancelled with Back after pushing other blocks → every block back where it started.
